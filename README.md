# 🥙 Lumpia Basah Kang Jamal - Static Landing Page

Repository ini berisi *source code* front-end untuk website katalog statis (landing page 1 halaman) UMKM kuliner "Lumpia Basah Kang Jamal" yang berlokasi di Cibinong. Website ini difokuskan pada kecepatan akses, responsivitas di berbagai perangkat, dan kemudahan konversi pelanggan langsung ke WhatsApp.

## 🚀 Teknologi yang Digunakan
*   **HTML5** (Struktur utama murni tanpa framework JS/Node.js)
*   **Tailwind CSS** (via CDN untuk styling yang cepat dan modern)
*   **Vanilla JavaScript** (Untuk logika ringan seperti *Intersection Observer* pada *floating badge*)
*   **Google Fonts** (Plus Jakarta Sans) & **Font Awesome** (Ikon)

## ✨ Fitur Utama
*   **Desain Responsif:** Tampilan yang menyesuaikan dengan sempurna baik di HP, Tablet, maupun Desktop.
*   **SEO Optimized:** Dilengkapi dengan Meta Tags lengkap, Open Graph untuk *sharing* sosial media, dan Schema.org JSON-LD (Format `FoodEstablishment`) agar mudah dikenali mesin pencari.
*   **Katalog Menu:** Menampilkan varian menu beserta harga dengan desain *card* yang menarik.
*   **Integrasi Google Maps:** Menampilkan peta lokasi untuk 2 outlet fisik secara langsung (via iframe).
*   **Direct to WhatsApp (CTA):** Tombol pemesanan *floating* dan di setiap menu yang langsung mengarah ke chat WhatsApp penjual beserta format pesan otomatis.
*   **Smart Floating Badge:** Menggunakan JavaScript `IntersectionObserver` untuk menyembunyikan *watermark* developer (MubaDev) secara otomatis saat user menggulir ke bagian footer.
